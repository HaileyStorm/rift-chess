# Current Worker semantics

This reduced matrix carries distinct contracts selected from the historical 004
inventory onto the current 2.0.35 candidate. It uses freshly checked/emitted
source and actual Windows Bun module workers, with clone and packed transport.
The original diagnostic, compiler, frozen proof inputs and browser package stay
unchanged.

`policies.bend` makes small results predictable without another compiler as the
oracle. The matrix checks caller-scoped argument requirements, permission after
returning from `never`, remote `never`, coalesced nested require with cap one,
strict local/remote conflicts, the actual conditional branch, and permissive
warning deduplication while `never` remains local. Concurrent required, never
and plain roots share one pool. A transparent wrapper holds authentic helper
results, reverses their delivery, and adds stale-epoch and duplicate copies.
Results stay in their original slots; plain/never roots gain no remote work.
Every session closes with zero outstanding work and retained data accounting.

The submission witness mutates a caller's shared DAG immediately after `submit`;
the remote computation returns the original independently calculated 87, while
the caller retains its mutations and alias. Disposal holds two actual helper
results with three roots outstanding, closes the session, and requires all three
promises to reject. Delayed results remain inert; listeners and helpers retire.
A separate generated fault module imports the real emitted helper and throws on
an assigned job. The actual Worker error closes the session without publishing
the held result.

F32 checks preserve signed zero and a rounded fraction. String checks preserve
Unicode scalars, NUL and an astral character. Nonfinite required inputs, malformed
UTF-16 and a small string budget reject before additional dispatch. A packed
reply witness changes one UTF-8 byte in an authentic result, preserving its
header and identity; the decoder rejects it with `protocol` and closes the pool.
These deliberate faults are negative boundary controls, not production failures.

An order-sensitive balanced four-leaf computation holds four authentic replies
from two forks, reverses them, and adds stale/duplicate copies. The independently
calculated result remains 2345. The same four-helper pool then runs three roots
concurrently: inner requests for eight helpers inherit an outer cap of two.
Each invocation's region helper sets stay within that cap, with both permitted
helpers witnessed. This is a finite nested-cap and compound-fork control, not a
proof for every program or scheduling pattern.
