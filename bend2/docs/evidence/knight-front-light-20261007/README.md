# Frontal knight lighting in the current candidate

The ivory knight's broad face was dull and the navy face lost its shape in the
default view. A frontal key light and a clamped polished highlight now expose
more of those planes. This changes RGB only: the triangulated sculpture, eye
geometry, placement, projection, shared quarter samples and alpha stay intact.
Other piece artwork and the atlas are unchanged.

Private rendered comparisons covered six cameras and both colors. All 12 full
alpha masks matched; transparent pixels retained zero RGB. A board comparison
against the preceding canonical Match package changed only the two knight RGB
textures. The gloss-only alternative was too subtle and was not selected.

Fresh scene and controller emissions use current source. The controller output
is byte-identical to the canonical Match milestone. The fresh browser package
is tested with actual Chrome pointer input on the muzzle, neck, eye region,
base and a transparent corner, followed by a same-Worker right drag. The eye
witness checks coverage and routing; it does not assert visual eye readability.
The offline check installs the service worker, compares online/offline initial
canvas PNGs, makes e2-e4 offline and reloads the exact saved record and position.
Execution results and source/package hashes are recorded in `acceptance.json`.

Run `node bend2/docs/evidence/knight-front-light-20261007/capture.mjs` for a
read-only byte capture. It pins the historical canonical Match manifest,
retains its 12 original consumers, and checks the original 315 creation inputs:
312 remain unchanged; State, Commands and KnightMesh have explicit postimages.
Fresh cache dependencies and every packaged file must match. The historical
canonical capture stays unchanged and rejects these current graphics bytes.

This is candidate application evidence. No new proof Workers were run and no
Safe, BendTT/kernel, native, GPU, physical-device or compiler adoption acceptance
is granted. The fixed light now differs from the atlas pieces' baked lighting.
The sculpture still looks coarse, and its eye and style consistency need work.
Owner WOW acceptance and stable overall responsiveness remain open.
