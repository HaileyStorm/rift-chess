# Prepared match core version 3

This additive implementation returns the canonical successor legal IDs alongside
an accepted move. Frozen v2 still decides whether the complete command is
enabled. The successor transition, repetition key, history, revision, policy,
offer and override remain exactly equal to the frozen result. Nonmove commands
use the existing facade. Balanced legal enumeration is unchanged.

The three bridge declarations in `core/v3/prepared-match/LAWS.bend` cover arbitrary
typed matches and commands: accepted-result erasure, exact ordered successor IDs,
and complete command-result erasure. The unchanged v2 proof runner checked their
fills with pristine accepted Bend 2.0.27, ownership checking, zero open terms and
its unsafe/foreign dependency screen. Its actual exit and Windows Job closure
were collected; the bound inputs remained unchanged. This is source-proof
authority under the accepted checker, not a Safe/BendTT or native benchmark.

Two mutations of the actual unfrozen implementation retained the final laws and
proofs. Carrying old-position IDs failed specifically at
`LAWS.carried_canonical`; using an old-position repetition key failed at
`LAWS.apply_exact`. Original bytes were restored after qualified native exit.
Raw failure terminals, diagnostics, mutant bytes and restoration receipts are
preserved without relabeling their exit code as success.

The final version's accepted-27 selected emission passed 61 complete frozen-result
and ordered-list comparisons. Cases include ordinary moves, capture, castling,
en passant, promotion, Shift, rejection, stale revision, Undo, offers/replies,
resignation, threefold and Auto100. Five positions discriminate old and successor
legal lists. These finite comparisons independently cover emitted behavior; they
do not replace the source bridge claims or establish browser latency.

`verify.mjs` checks the retained v2 freeze, exact new sources, current compiler and
loader identities, imported frozen dependency cone, actual positive/negative
receipts, emitted-module/differential chain and an independent review binding.
Its creator refuses to overwrite `laws/semantic-prepared-v3.json`. The evidence
copies of the probe, emitter and differential are provenance, not runnable entry
points from this directory.

This core version does not select a UI or browser build. Integration must consume
the immediate result of `Match.command`; an independently constructed
`MoveAccepted` value or UI legal cache has no pairing guarantee. The 62 passing
desktop/portrait comparisons of the private UI prototype remain supporting
evidence. Actual integrated UI updates, staged Tick commits, animation, effects,
subsequent browser interaction and source-bound performance comparisons remain
separate acceptance work.

The private accepted-27 probe retained its forward-slash, namespace-preload and
bare-constructor-tag adapter failures before the corrected runs. The candidate
2035 probe and its earlier failures also remain retained. Neither those probes
nor this version move the accepted compiler pin or close the 2.0.35
Safe/kernel, Worker, native, GPU or reviewed-amendment requirements.
