# Rejected motion layer trial

The R7 trial skips live and dying layers whose complete texture/contact support
lies outside the partial motion rectangle. Invalid source or geometry keeps
the original draw path. Painter order, sampling and the final outside-pixel
restoration remain unchanged. This trial is **not selected for production**.
The published BoardScene and browser-builder bytes were restored exactly.

The private finite trial passed 54 complete 512-pixel RGBA/outside-pixel pairs
across five actual legal move/capture/castle/en-passant/promotion fixtures and
nine view cohorts, plus six corrected transparent/opaque alpha pairs. Independent
review verified the production port of the same 12 helpers. A fresh source-bound
scene emission and browser package passed with closed original native handles
and Jobs. The finite matrix was not repeated after an equivalent helper port.

One installed-Chrome pair then exercised two fresh browser contexts and 12
native canvas actions, including e4 and e5. Both packages displayed natural
intermediate motion and completion, supplied valid increasing mask offers,
avoided unused moving ground/preparation work and produced equal final PNGs.

| Observation | Published baseline | R7 candidate |
| --- | ---: | ---: |
| e4 input to canvas | 301.2 ms | 349.5 ms |
| e4 sprite construction | 48.3 ms | 54.6 ms |
| e5 input to canvas | 252.2 ms | 259.1 ms |
| e5 sprite construction | 20.4 ms | 13.1 ms |
| First playable frame | 1764.0 ms | 4176.3 ms |
| First detailed frame | 3978.3 ms | 8569.7 ms |

The warmed renderer gain does not establish an overall browser benefit. The
candidate was rejected rather than adding complexity without demonstrated
product improvement. A single fixed-order pair under variable host load does
not prove the guards caused the observed regressions or establish stable
latency. Pointer timing contains sprite work; tree, traversal and pixel timings
overlap. They must not be summed as independent costs.

The machine-readable [disposition](disposition.json) binds the actual sources,
emitted package, native terminals and retained private result paths/hashes.
Candidate source bytes, all original failed attempts and emitted outputs remain
under the task's reserved artifact tree. There is no new application capture
amendment because the application inputs returned exactly to their published
bytes. Existing historical capture records remain unchanged.

This is finite graphics and local browser evidence. It supplies no general
proof, constrained-device, physical scanout, owner visual, offline, native CPU,
GPU or compiler-adoption acceptance. The full sprint remains active; Linux STOP
and the original GPU failure remain unresolved.
