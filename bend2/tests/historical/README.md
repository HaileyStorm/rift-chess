# Historical browser harnesses

These scripts reproduce the published v1 hybrid-host scenarios and their immutable
receipts. They require the DOM and worker protocol at source revision
`e612643f9158881a4765fb3d7b2f4aeeb4d9a93e`; they are not current application gates.
The handwritten application host has been replaced by Bend pixel UI. Current
rendered interaction is tested by `../native-browser.mjs`.

Retain these three scripts while the v1 verification receipts remain part of the
law and deployment lineage. Do not use them to claim acceptance of the current UI.
